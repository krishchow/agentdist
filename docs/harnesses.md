| Harness | An MCP tool | Invoking a skill |
|---|---|---|
| Claude Code | mcp__server__tool | /name |
| Codex | mcp__server__tool | $name |
| Cursor | `tool` (server MCP tool) | /name |
| GitHub Copilot | server-tool | /name |
| Gemini CLI | mcp_server_tool | the `name` skill |
| OpenCode | server_tool | the `name` skill |
| Factory Droid | `tool` (server MCP tool) | /name |
| Devin (Windsurf) | `tool` (server MCP tool) | /name |
| Cline | `tool` (server MCP tool) | /name |
| Kilo Code | server_tool | /name |
| Qwen Code | mcp__server__tool | /name |
| Amp | `tool` (server MCP tool) | the `name` skill |
| pi | mcp__server__tool | /skill:name |
| Goose | `tool` (server MCP tool) | /skills name |
| Zed | mcp:server:tool | /name |

Content in the shared `.agents/skills` directory is rendered in a portable dialect instead (the
tool and its server named in prose), because no one harness's identifier is right for all of its
readers.
